# Novel Timeline Workbench — Planning Pack

This planning pack describes an MVP for an interactive, frontier-controlled narrative structuring tool for novels.

Files:

1. `01_overall_tool_description_and_user_flow.md`
   - Product framing
   - User flow
   - MVP scope
   - Core principles
   - Non-goals

2. `02_component_definition.md`
   - Major system components
   - Responsibilities
   - Inputs/outputs at a conceptual level
   - Suggested MVP vs later components

3. `03_component_interactions.md`
   - End-to-end workflows
   - Upload/index flow
   - Frontier analysis flow
   - Correction/recomputation flow
   - Visualization/update flow

This pack intentionally avoids detailed API contracts and database schemas. It is meant to guide an initial coding-agent implementation plan.
