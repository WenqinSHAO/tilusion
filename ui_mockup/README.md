# Novel Timeline Workbench — Prototype 01

Open `index.html` directly in a browser. No build step and no backend are required.

This prototype is intentionally fake-data-driven. It is meant to test the first UX loop before wiring the real extraction backend:

- two-pane source text + reading-synced timeline
- scroll synchronization in both directions
- clickable event cards
- clickable entity and thread filters
- source-span highlighting
- bottom LLM answer drawer with clickable citations
- basic reading / thread / review mode switches
- explicit uncertainty and review affordances

The sample text, entities, events, and threads are synthetic placeholders. Replace them later with extracted data from the LLM/backend pipeline.
